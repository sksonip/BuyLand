# BuyLand — Learning Fork

A fork of [PassionOverPay/BuyLand](https://github.com/PassionOverPay/BuyLand), an ASP.NET Core MVC land-buying application.

This repository is retained for experimentation. The original application is upstream work; it is not presented as an independently built production product.

## Development

Requires the .NET 8 SDK.

```sh
git clone https://github.com/sksonip/BuyLand.git
cd BuyLand
dotnet restore
dotnet run
```

Use the local URL printed by the application. This documentation update does not establish runtime verification or production readiness.

Generated `bin/`, `obj/`, and per-user project settings are excluded from source control. Existing open pull requests should be reviewed before further maintenance.
