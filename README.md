# BuyLand

A land buying app in MVC.

## Overview

BuyLand is a simple web application built using ASP.NET MVC that lets users browse and purchase land plots.

## Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (version 8.0 or later)
- A code editor such as Visual Studio or VS Code
- [Git](https://git-scm.com/) for version control

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/PassionOverPay/BuyLand.git
   cd BuyLand
   ```
2. Restore the dependencies using the .NET CLI:
   ```bash
   dotnet restore
   ```

## How to Run

1. Build and run the application from the project root:
   ```bash
   dotnet run
   ```
2. Once the application starts, open your web browser and navigate to the URL shown in the console (typically https://localhost:5001).
